# Kit ACR-8D — Frontend

Interfaz en React + TypeScript + Vite + Tailwind. No contiene llaves ni SDK de IA:
todas las operaciones se hacen contra el backend (`/api`).

```bash
npm install
npm run dev     # http://localhost:3000, redirige /api a http://localhost:8080
npm run build   # genera dist/ para publicar como sitio estático
```

Ver el README de la raíz del repositorio para la arquitectura completa.
